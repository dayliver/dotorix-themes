# dotorix-themes

Public mirror of [Dotorix](https://github.com/dayliver) theme CSS and fonts for the in-app gallery CDN.

- **SSOT for editing:** the DotoriX app repo (`app/public/themes`, `app/public/fonts`).
- **This repo:** publish mirror only — do not treat it as the only copy.

## CDN (jsDelivr)

```
https://cdn.jsdelivr.net/gh/dayliver/dotorix-themes@main/themes/<id>/
https://cdn.jsdelivr.net/gh/dayliver/dotorix-themes@main/fonts/<slug>/
```

Fonts are OFL (or vendor) licensed; keep `font-face.css` URLs and file names unchanged.
